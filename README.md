# upwind-time

方向选择与时间投入的元方法论：别追"伟大的目标"，把位置挪到上风口，选难而正确的方向，用足够长的时间把它填满——**伟大是结果，不是起点。**

一句话：**判断标准只有一个——五年后，这个方向是更值钱还是更不值钱。**

## 方法论底座

- 奥卡姆剃刀：剃掉举例/场景/作者/书名 → 最小内核「一个人该把时间押在哪，才可能做出有价值的事」
- 上风口：下风口短期省力长期被推着走；上风口一开始逆风，越往后越被时代托举
- 难而正确："伟大"写成目标就会骗人（忙/产出/交差都能伪装成伟大）；真正的问法反过来——够难吗、有前景吗；热情与难度在交汇处落脚
- 时间填满缝隙：缝隙不是聪明看出来的，是时间泡出来的；熟到看见"本该如此、却不是如此"的违和感时，突破性想法才出现——这就是壁垒的来源
- 乐趣是燃料：不是"轻松好玩"，是"持续想往下挖"的牵引力；只靠顿悟驱动的人会枯竭

## 解决什么

| 痛点 | 本技能的做法 |
|---|---|
| 时间都花哪了、为什么没成长 | 风向筛：每周排期前把待办分上风口（复利累积）/下风口（做完即清零）；硬规则 ≥30% 时间落上风口 + 锁日历 + 排精力最好时段 |
| "伟大/战略性"叙事骗人 | 反向三问替代目标管理：够难吗（参照系检验）/三年后还成立吗（需求结构性检验）/带出什么下一步（≥3 条枚举）；挂两问砍掉或降级；结论落任务卡 |
| 慢项目总被快活吃掉 | 快慢双仓：快仓设容量上限+留缓冲；慢仓 1-2 个、四要素立项（具体名字/季度证据标准/每周小时数/退出判据）、不看周报只按季度检查"是否还在往前挪"（E1/E2/E3 证据标准，防"在积累"式自我欺骗） |
| 看得见别人看不见的（壁垒从哪来） | 缝隙笔记：固定收集位只记"这里不对劲"（三类违和感），每条 <2 分钟，记异常不记待办；同类 ≥3 次才升级（防噪音）；三种出口（慢仓项目/选题方法论/升职叙事素材） |
| 坚持不下去/感觉枯竭 | 乐趣月度校准："想知道下一步"的冲动是方向信号；连续两月为否 = 方向错了（不是意志力问题），回①重看风向 |
| 不知道五年后自己值多少 | 唯一判据收口：五年后这个方向更值钱还是更不值钱（"现在舒服"是下风口的特征不是优点） |

## 安装

复制本目录到 `~/.agents/skills/`（或你的 Skill 加载路径）即可。

## 自检

```bash
python scripts/validate.py tests/sample_good.json   # 必须 exit 0
python scripts/validate.py tests/sample_bad.json    # 必须 exit 1
```

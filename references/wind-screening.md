# 风向筛实操：上风口/下风口的判断与锁位

> 核心：风向筛是每周排期前的第一道闸——**上风口 = 做完后能力/资源/认知会复利累积；下风口 = 做完即清零、明年还得重来。** 判断标准只有一个：五年后，这个方向是更值钱还是更不值钱。

## 一、判据细化：资产 vs 消耗

### 核心判问（30 秒定类）

```
"这件事做完，半年后我不再做它，它留下的东西能独立继续产生价值吗？"
  能 → 上风口（资产：系统还在跑、能力还在身上、关系还在、资产还能复用）
  不能 → 下风口（消耗：做完就没了，下次还得从头来）
```

### 上风口四类（复利来源不同，检查方式不同）

| 类 | 复利来源 | 半年后的证据 | 典型 |
|---|---|---|---|
| 搭系统 | 系统本身在替你干活 | 系统还在跑且省了时间（可数） | 自动化流程、个人知识库、校验器 |
| 学底层 | 能力长在身上 | 能回答半年前答不出的问题（可列举） | 读源码、啃理论、做拆解 |
| 建关系 | 信任在对方身上 | 对方还愿意帮你（可列举最近一次） | 深聊、求助、被推荐 |
| 做可复用资产 | 资产本身可重复使用 | 资产被再次使用（可数次数） | 模板、提示词库、方法论、样例代码 |

### 下风口三类（清零方式不同）

| 类 | 清零方式 | 识别信号 |
|---|---|---|
| 重复救火 | 火灭了就没了，下次还烧 | 同类问题第 3 次出现（该建系统了，还在人肉救 = 下风口） |
| 纯执行搬运 | 做完即交付，交付即归零 | 过程不产生可带走的东西（数据/认知/关系） |
| 为交差而交差 | 检查方满意即结束 | 交付后你什么都没学到、下次的做法和这次一模一样 |

### 分不清时的半资产判据

有些任务看着像下风口，但做完会沉淀一点东西（如"整理一次数据，顺便摸清了数据口径"）：

```
判据：沉淀的东西"下次能直接用"吗？
  能（数据口径文档下次直接省 2 小时）→ 记为"半资产"，归上风口，
      但要在任务卡里写明"资产产物是什么"（不写明 = 下次还是纯搬运）
  不能（这次整理的方式下次还得重新想）→ 下风口
半资产的纪律：每个半资产任务必须产出"资产产物"，
  产不出 = 下次自动升级判断（可能根本不是半资产）
```

## 二、30% 地板的锁位方法（防"有空就做"）

```
为什么必须锁日历：
  "有空做上风口的事" = 上风口永远排在快仓后面 = 快仓永远有空 = 上风口永远没空
  上风口时间不锁进日历，30% 是愿望不是排期
锁位方法：
  1. 算数：每周工作时间 × 30% = 上风口小时数（例：40h 周 → ≥12h）
  2. 找段：精力最好的时段（例：周二/周四上午 9-12 点）
  3. 锁死：日历上写"慢仓/上风口"（不写具体任务名——写死任务名会让
     临时交付挤掉它时你心疼；写"慢仓"这个占位符，挤占的代价是心理可见的）
  4. 防御：锁定时段不排会（能推的推，不能推的换时段换人）
每周复盘只查一个数：本周上风口实际用了 __h / 应 ≥__h（达成/未达成）
```

**被挤占时的应对**（不是"忍"，是机制）：
```
挤占发生 → 当周不补（补=用下风口的时间还上风口，等于下风口变多）
  改为：下周排期时优先恢复被挤占的小时（日历上标"还债"）
  连续 3 周被挤占 → 结构问题（快仓本身超载 or 上风口时段选错），
    重排结构：快仓砍活（哪些快仓任务其实可以砍/降级/交出去）
    或换精力时段（你的"精力最好时段"可能判断错了，实测一周精力曲线）
```

## 三、每周 15 分钟排期模板

```markdown
# 风向筛 <周次>
## 1. 待办清单（全部，不遗漏）
| # | 任务 | 上/下/半资产 | 判据一句话 | 资产产物（半资产必填） |
|---|---|---|---|---|
## 2. 上风口时间账
本周可用工作时间：__h
30% 地板：__h
已锁时段：<日历位置>
## 3. 落位
上风口（≥__h，锁死）：<任务+时段>
快仓：<任务+时段>
半资产任务：<任务> → 资产产物：<什么>
## 4. 砍/降级（反向三问挂两问的）
<任务>：三问结论 <难?/三年?/下一步?> → 砍/降级为 <什么>
## 5. 上上周实际（对账）
上风口实际 __h / 应 ≥__h（达成/未达成，未达成原因：__）
```

## 四、"五年后更值钱"的使用边界

```
这是方向争议时的唯一收口判据，不是每个任务的判据：
  任务级（这周做哪个）→ 用上/下风口判问（资产vs消耗）
  方向级（该学什么/该往哪走）→ 用五年判据
误用警告：
  ✗ 用五年判据砍单个任务（"这个任务五年后不值钱"= 五年尺子量周活）
  ✗ 用"现在舒服"替代五年判据（"做这个不累"≠"五年后更值钱"，
    下风口恰恰是现在最舒服的——省力是它的特征，不是优点）
  ✓ 五年判据的表述：五年后，做这件事积累的能力/资产/位置，
    在市场上的相对价值是上升还是下降（看的是相对，不是绝对）
```

## 五、常见误判（风向筛特化）

| 误判 | 为什么错 | 正确 |
|---|---|---|
| "学新工具"都算上风口 | 工具会过时；学"用这个工具干活"是消耗，学"这个工具背后的能力"才是资产 | 问：这个工具明年没了，我学到的还留着吗？（API 操作不留，思维方式留） |
| "社交应酬"算建关系 | 单次应酬=消耗；建关系=持续信任积累（能互相求助） | 问：这个人半年后我还愿意联系吗？联系是为了什么具体价值？ |
| "救火"都是下风口 | 第 3 次救同一类火时，"建防火系统"是上风口（把重复消耗转成资产） | 问：这类火还会再烧吗？会 → 防火系统上风口；不会（一次性）→ 救火下风口 |
| "写周报"纯消耗 | 周报可以是下风口（为交差）也可以是半资产（写清本周判断=决策日志） | 问：半年后回看这份周报，它是什么？（废纸=下风口；决策依据=半资产） |
| "上风口=不赚钱的事" | 上风口可以赚钱（可复用资产=产品雏形）；下风口也可以赚钱（纯搬运赚快钱） | 上/下风口是"复利"维度，不是"当下收益"维度；两者正交 |

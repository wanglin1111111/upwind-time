# 反向三问：替代目标管理的判断工具

> 核心：别先问"目标是什么"，先问——**够难吗？三年后还成立吗？做成后会自动带出什么下一步？** 三问里挂两问的，砍掉或降级。

## 一、为什么三问替代目标管理

```
"伟大"写成目标后的欺骗路径：
  目标="做一件伟大的事" → 今天很忙（伟大吗？忙像伟大）→ 有产出（伟大吗？产出像伟大）
  → 能交差（伟大吗？交差像伟大）→ 一年后发现：伟大没发生，忙碌完成了
  根因：叙事型目标只能被叙事型证据满足（忙/产出/交差都是叙事）

三问的防欺骗结构：
  每个问题都从"属性"判断，属性可以被证伪，叙事只能自我感觉
  Q1 难度 → 参照系检验（对谁难？谁都能做=不难）
  Q2 三年 → 外部事实检验（行业/技术/需求的客观变化）
  Q3 下一步 → 结构检验（做成后的世界有没有路可走）
  属性检验不依赖"我觉得这件事很伟大"——依赖外部可查的事实
```

## 二、三问各自怎么问才不自我欺骗

### Q1 够难吗？（不难的事护不住你）

```
问法：这件事对"这个领域里已经会了的人"难吗？
  参照系必须是"该领域已有能力的人"，不是"我"
  我只觉得难 → 可能是我不会（学习曲线），不是它难（壁垒）
  别人也会 → 没有壁垒，谁都能做 = 做成了也不值钱
  判定：
  ✓ 领域内的人做了会卡住（需要新方法/新组合/新深度）
  ✓ 难在"做出来"（有明确产出判据的难）
  ✗ 难在"说不清要做什么"（模糊的难=还没想清楚，先想清楚再答 Q1）
  ✗ 难=苦（体力消耗大≠难度高；搬运 10 吨很苦不难）
```

### Q2 三年后它还成立吗？（不成立的现在再忙也是空转）

```
问法（三个证伪点，任一不成立即挂）：
  a) 需求还在吗？（三年后有人要这个结果吗——看需求来源是结构性的
     还是风口性的：人口/消费/法规结构变化=结构性；单一事件/补贴=风口性）
  b) 手段还成立吗？（做这件事依赖的技术/平台/政策，三年后会被什么替代？
     被替代=手段不成立——注意：手段变了但需求还在 = 不挂，Q2 问的是需求+价值，
     不是工具）
  c) 价值还在吗？（三年后这件事做成了，它的相对价值是升是降——
     和五年判据同构，只是时间窗更短）
判定：a/b/c 全过 → 成立；a 挂 → 方向错（最致命）；b 挂 → 手段要换但方向可对
```

### Q3 做成了会自动带出什么下一步？（带不出下一步的是终点）

```
问法：想象它 100% 做成了。接下来自然会发生什么？
  枚举法（强制列 ≥3 个，列不出=挂）：
  "做成之后，__（某类人/某件事）会因此 __（发生什么变化）？"
  ✓ 能列出 ≥3 个自然延伸（客户会来要 X / 团队会想扩 Y / 方法可以迁移到 Z）
  ✗ 只能列出 1 个（"能交付了"）→ 终点（交付即结束，没有复利）
  判据的本质：Q3 检验的是"这件事是不是一个系统的入口"
  终点=单点（做完就停了）；上风口=入口（做完后面还有门）
```

## 三、常见三问误用

| 误用 | 症状 | 纠正 |
|---|---|---|
| 拿叙事答属性 | Q1"这件事很重要"（重要≠难）；Q2"这个行业很有前景"（前景是感觉不是证伪） | 属性问题必须用可检验的证据答：参照系/需求结构/延伸枚举 |
| 把难当苦 | "这件事要加班所以很难" | 苦=消耗，难=壁垒；加班多但谁都能干 = 下风口 |
| 把长当三年 | "这件事我要做三年所以三年后成立"（时间投入不产生持续性） | Q2 问的是外部世界（需求/手段/价值），不是你的投入计划 |
| 三问全过=必做 | 三问过了就 all-in | 三问是"准入"不是"优先级"：过了=可以做；做不做还要看 Q1-Q3 的强度（难得多强/三年多稳/下一步多近）+ 你当前慢仓的位置 |
| 只对新方向问 | 老任务/慢仓项目从不重问 | 慢仓项目每季度重过一次三问（世界在变，当时的"三年成立"可能已经不成立） |

## 四、任务卡格式（三问结论落盘）

```markdown
## 反向三问 <任务名> <日期>
Q1 够难吗？
  参照系：<该领域已有能力的人>
  判定：过/挂（一句话证据）
Q2 三年后成立吗？
  a) 需求：<结构性/风口性>，证据：<什么>
  b) 手段：<会被什么替代>，证据：<什么>
  c) 价值：升/降，证据：<什么>
  判定：过/挂
Q3 带出下一步吗？（列 ≥3 个）
  1. <做成之后，__会__>
  2. <做成之后，__会__>
  3. <做成之后，__会__>
  判定：过/挂
结论：三问 <3过/2过1挂/≤1过> → 做/降级/砍
降级方案（若挂但保留）：<降级成什么（例：从慢仓项目降为快仓一次性任务）>
```

**落盘的价值**：季度复盘时回看"当时为什么收了这个任务"——三问答案在卡上，你的自我欺骗（"当时觉得很重要"）无处藏身。

## 五、三问与风向筛的关系（不重复，分工明确）

```
风向筛（周级，排期前）：
  作用域：已有的待办（已经决定要做的）
  问题：这件事做完是资产还是消耗？（上/下风口）
  频率：每周一次
反向三问（任务级，接入前）：
  作用域：新的任务/方向（还没决定要不要做的）
  问题：这件事本身值不值得做？（难/三年/下一步）
  频率：每个新任务一次 + 慢仓项目每季度一次
衔接：
  新任务 → 三问（挂两问=砍/降级，不进排期）
  过了三问的任务 → 进排期 → 风向筛（定上/下风口落位）
  慢仓项目 = 三问过 + 上风口 + 难而正确（三者交集）
```

# 别追伟大目标，挪到上风口：难而正确 + 时间填满

> 源材料：「上风口/难而正确/时间填满」方向选择方法论拆解
> 本文为 `upwind-time` 技能的方法论底座；可执行工作流见 `../SKILL.md`。

## 一、奥卡姆剃刀：剃到只剩骨头

剃刀过程（如无必要，勿增实体）：

- 表层元素：夜逛街头、YC创始人的书、A和B的选择、数学vs微积分、AI、伟大工作、时间积累、乐趣…… → 这些是载体和举例

- 再剃掉"作者是谁、书叫什么"→ 剩下「一个人该把时间押在哪，才可能做出有价值的事」

**最小内核（唯一不可再删的主题）：别去追一个"伟大的目标"，而是把自己的位置挪到上风口，选难而正确的方向，然后用足够长的时间把它填满——伟大是结果，不是起点。**

## 二、核心提炼

**① 上风口｜选方向先看风向，不看当下舒服**

不是"哪个现在最顺手"，而是"哪边是风吹来的那一侧"。下风口的选择短期省力、长期被推着走；上风口的选择一开始逆风，但越往后越被时代托举。判断标准只有一个：**五年后，这个方向是更值钱还是更不值钱。**

**② 难而正确｜要做伟大的工作，而不是定伟大的目标**

"伟大"一旦被写成目标，就会骗人——今天很忙、今天有产出、今天能交差，都能伪装成伟大。真正的问法是反过来的：这件事是否足够难、是否足够有前景？如果是，哪怕今天看不见成果，也继续往前推。热情和难度不矛盾，要在两者交汇处落脚：**既有热情，又难得住人。**

**③ 时间填满缝隙｜在一个领域泡够久，才看得见别人看不见的东西**

专业领域的"缝隙"不是聪明看出来的，是时间泡出来的。当你对某件事熟到看见"这里本该如此、却不是如此"的违和感时，突破性的想法才会出现。这就是壁垒的来源。

**④ 乐趣是燃料｜选能持续产生新知识、且让你有兴致的状态**

只靠顿悟驱动的人会枯竭；靠乐趣和新知识驱动的人能跑长跑。乐趣不是"轻松好玩"，而是"持续想往下挖"的那种牵引力。

## 三、落到工作流的行动指南

**1. 入口：给任务加一道"风向筛"**

每周排期前，把所有待办分成两类：

- **上风口**：做完后能力/资源/认知会复利累积的（搭系统、学底层、建关系、做可复用的资产）
- **下风口**：做完即清零、明年还得重来的（重复救火、纯执行搬运、为交差而交差）

**硬规则：每周至少 30% 的工作时间必须落在上风口，且这部分时间优先安排在精力最好的时段，不可被临时会议挤占。**

**2. 决策：用"反向三问"替代目标管理**

接到任务或想启动一件事时，别先问"目标是什么"，先问三个问题：

- 这件事**够难**吗？（不难的事护不住你）
- **三年后它还成立**吗？（不成立的现在再忙也是空转）
- 如果它做成了，**会自动带出什么下一步**？（带不出下一步的，是终点不是上风口）

**三问里挂两问的，砍掉或降级。**

**3. 过程：建一个"缝隙笔记"**

在日常工作流里开一个固定收集位（文档/笔记都行），只记一类东西："这里不对劲"——流程里说不通的环节、用户反复抱怨却没人改的点、行业里大家默认但其实没道理的做法。**每周复盘时翻一遍，这些违和感就是你领域的缝隙，也是选题、创新、升职叙事的原料库。记的是异常，不是待办。**

**4. 节奏：设"难而正确"的慢仓位**

把工作拆成两个仓：

- **快仓**：交付、响应、日常指标——保证今天能活
- **慢仓**：难、短期没回报、但方向明确的事（比如啃底层能力、做一个长期项目）——保证三年后你在上风口

**慢仓不看周报、不设短 KPI，只按季度检查一次"是否还在往前挪"。它被牺牲掉的那天，就是你开始滑向下风口的那天。**

**5. 续航：用乐趣做定期校准**

每月问自己一次：现在做的事，还能让我产生"想知道下一步"的冲动吗？如果连续两个月答案为否，那不是意志力问题，是方向选错了——回到第①条重新看风向。

**一句话收尾：把"我要做成什么"换成"我站在哪、往哪走、能走多久"。**
